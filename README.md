# astrbot_plugin_poetry_guess（猜诗句）

从诗词游戏引擎（astrbot_plugin_poetry_games）拆出的**猜诗句插件**：Wordle 式猜诗句 + 劫难系统 + 道具系统 + 诗词对垒。

## 依赖

| 插件 | 依赖方式 |
|---|---|
| [astrbot_plugin_poetry_base](https://github.com/sfw2099/astrbot_plugin_poetry_base)（诗词底座） | 诗词库检索/校验/随机出题、个人诗句积累。**未安装或库未下载时提示安装**，游戏无法开局 |
| [astrbot_plugin_qiuye](https://github.com/sfw2099/astrbot_plugin_qiuye)（秋烨枢纽） | 成就解锁/道具背包/抽道具保底/使用记录。未安装时成就与道具静默跳过，游戏本体不受影响 |

## 指令

| 指令 | 说明 |
|---|---|
| 猜诗句 `[格式] [声\|形]` | 开局。格式：4/5/6/7 单句或 44/34/43/55/77 两句（缺省随机）；声=拼音提示 / 形=部首提示 |
| `cc 诗句` | 猜测（两句需带标点），每字汉字/声母/韵母/声调独立着色 |
| 提示 / 声韵提示 / 拼音提示 | 查看声母韵母状态图（仅拼音模式） |
| 当前劫难 | 图片渲染本局劫难 |
| 结束猜诗句 | 结束当前游戏并揭示答案 |
| 猜诗句帮助 | 帮助菜单 |
| 诗词道具 `<名称> [数量] [参数]` | 使用道具 |
| 抽道具 `<诗句>` | 接一句**库中且你未积累过**的诗句，随机概率获得道具（连抽递增，保底至 100%） |

## 劫难系统

开局有概率（默认 20%，可配置）引来 1~N 重劫难（默认最多 5 重）：

| 劫难 | 效果 |
|---|---|
| 一缺抱憾 | 每次猜测后随机使该句某一格变空白 |
| 七步成诗 | 每猜满 7 次未结束，换含某字的新题 |
| 大音希声 | 本局不显示声调 |
| 三缄其口 | 无法使用提示类道具与「提示」命令 |
| 雁过无痕 | 含正确答案汉字的非答案句整行隐藏 |
| 过眼云烟 | 只显示最近 5 句 |
| 白驹过隙 | 最多 15 次猜测，超限判负 |
| 推陈出新 | 只能使用所有参与者都未积累过的新句（答案本身除外） |
| 一脉相承 | 除首句外，每次猜测须与上一句共享汉字 |

- 通关含劫难的一局 → 所有参与者解锁对应劫难成就
- 升级制成就【x重天】：记录历史最高一局劫难数（一重天~九重天封顶）
- 道具【招灾】开局追加劫难、【解难】随机解除劫难；有劫难的局通关后每人必得招灾/解难其一（替换普通掉落）

## 道具

火眼金睛 / 三仙归洞 / 仙人指路 / 定仙游（换含字题）/ 探囊取物（偷道具）/ 招灾 / 解难，以及对垒回合类：乐不思蜀（跳过对方回合）/ 金蝉脱壳（私聊换自己的题）/ 百战不殆（免疫）/ 孤注一掷（追加回合）/ 请君入梦（系统代猜）。

## 诗词对垒

`/诗词对垒 [@某人|留空] [格式] [声|形]` → 对方回复【接受】→ **双方私聊**机器人 `cc 诗句` 出题 → 群内互猜对方诗句，先猜中者胜。支持全部道具互动。

## 数据架构

```
诗词库/诗句积累  → 诗词底座（astrbot_plugin_poetry_base）
成就/道具/保底   → 秋烨枢纽（astrbot_plugin_qiuye）
本插件数据目录   → 仅渲染图等临时文件
```

成就/道具 id 与旧版 astrbot_plugin_poetry_games 一致，玩家数据无缝衔接。

## 从旧版迁移（手动）

| 旧 | 新 |
|---|---|
| `astrbot_plugin_poetry_games/poetry_data.db`、`players/{uid}.json` 的 verses/诗词stats | 诗词底座（见底座 README） |
| `players/{uid}.json` 的 achievements/inventory/draw_bonus | 秋烨 `users/{uid}.json`（见底座 README 的合并脚本） |

## 配置项

| 项 | 默认 | 说明 |
|---|---|---|
| hazard_rate | 20 | 劫难触发概率(%) |
| hazard_max | 5 | 劫难最大重数（1~9） |
| verse_max_attempts / verse_min_len / verse_max_len | 10 / 7 / 18 | 引擎参数（引擎实际字数边界为 4~7 字单句或两句组合） |

## 暂未迁移

邀战猜诗词、AI bot 对战（仍留在旧插件 astrbot_plugin_poetry_games，后续版本迁移）。
